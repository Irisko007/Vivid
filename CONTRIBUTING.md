# Contributing

Vivid was created for personal use with AI assistance. Focused fixes and translation improvements are welcome.

## Before changing code

- Search existing issues and describe the problem or proposed change.
- Keep playback in mpv and avoid adding a browser runtime or background services.
- Keep interface motion short and preserve keyboard access.
- Put user-visible strings behind `tr()` and update the translation catalogs.
- Preserve settings, original media and the windowed external-file workflow.

## Pull requests

Use a focused branch. Explain what changed, include screenshots for UI changes, and state exactly what you verified. Do not claim checks you did not perform. Mention AI assistance when used.

See [development setup](README.md#development), [translation guide](docs/translations.md) and [security reporting](SECURITY.md).
