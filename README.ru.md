## Установка

### Автоматическое скачивание

Нужны `bash`, `curl`, Python 3.10+, `tar` и `sha256sum`.

```bash
curl -fsSL https://raw.githubusercontent.com/Irisko007/Vivid/main/scripts/download-install.sh -o /tmp/vivid-install.sh
bash /tmp/vivid-install.sh --install-deps --default
```

Скрипт скачивает последний релиз, проверяет SHA-256, устанавливает приложение в `~/.local/share/vivid/app` и добавляет ярлык. Повторный запуск обновляет установку. Библиотека и настройки хранятся отдельно.

| Параметр | Действие |
|---|---|
| `--install-deps` | Установка системных зависимостей через sudo в Debian/Ubuntu, Fedora, Arch и openSUSE; на NixOS используется Nix. |
| `--default` | Назначение Vivid видеоплеером по умолчанию для текущего пользователя. |
| Без параметров | Установка с уже имеющимися зависимостями. |

Доступность пакетов зависит от дистрибутива и подключённых репозиториев. Если пакет отсутствует, установите его вручную и повторите запуск без `--install-deps`.

### Из исходников

```bash
git clone https://github.com/Irisko007/Vivid.git
cd Vivid
./install.sh --install-deps --default
./run.sh
```

На NixOS достаточно `./install.sh --default`: установщик соберёт Nix-пакет. На других дистрибутивах создаётся локальная `.venv`. Нужны **mpv**, **FFmpeg** для миниатюр, библиотеки Qt XCB и **xdg-utils** для ассоциаций.

### Запуск

```bash
~/.local/bin/vivid                    # Библиотека
~/.local/bin/vivid '/путь/видео.mkv'    # Оконный просмотрщик
~/.local/bin/vivid --viewer           # Пустой просмотрщик
./set-default.sh                     # Назначение по умолчанию отдельно
```

Графическая среда: **X11** или **Wayland с XWayland**. Нативное встраивание под Wayland пока не поддерживается. Добавьте `~/.local/bin` в PATH для короткой команды `vivid`.

## Возможности

- Отдельное перемещаемое и изменяемое окно при открытии видео.
- Аппаратное декодирование mpv с программным резервом, без браузерного движка.
- Библиотека, избранное, очередь, продолжение просмотра и автопереход.
- Субтитры, аудиодорожки, снимки кадров и скорость 0.25–2×.
- Вписывание, заполнение с обрезкой и растягивание без перекодирования.
- Шесть тем, предварительный просмотр темы и короткие анимации.
- Скрытие управления через 2,5 секунды. Открытые извне файлы остаются в окне.
- Атомарное сохранение настроек. Без аккаунта, телеметрии и облачного хранения.

MP4, MKV, WebM, MOV, AVI и другие форматы зависят от кодеков установленного mpv/FFmpeg. При импорте папки учитываются файлы непосредственно внутри неё.

## Языки

**При первом запуске используется английский.** Откройте **Settings → Interface language**, выберите язык: весь интерфейс, включая открытые настройки, сразу изменится без перезапуска видео. Нажмите **Save**, чтобы сохранить выбор. **Cancel** или закрытие настроек вернут прежний язык. Автоматическое сохранение библиотеки не сохраняет предпросмотр. При повторном запуске восстановится сохранённый язык.

English · Русский · Українська · Deutsch · Español · Français · Português · 简体中文 · 日本語 · العربية

Арабский интерфейс отображается справа налево. Для выбранного языка нужны системные шрифты. IBM Plex Sans включён в приложение; для других письменностей Qt использует системные шрифты.

## Управление

| Клавиши | Действие |
|---|---|
| `Ctrl+O` | Открыть видео |
| `Space` | Воспроизведение / пауза |
| `←` / `→` | Перемотка на 10 секунд |
| `↑` / `↓` | Громкость |
| `M` | Отключить звук |
| `F` / `F11`, двойной щелчок | Полный экран |
| `Esc` | Выйти из полного экрана |
| `Ctrl+←` / `Ctrl+→` | Предыдущее / следующее видео |
| `Ctrl+P` | Очередь |
| `Ctrl+S` | Снимок кадра |
| `Ctrl+L` | Поиск в библиотеке |
| `Ctrl+Q` | Выход |

Настройки и переход в библиотеку доступны из меню **…** просмотрщика.

## Данные

| Данные | Расположение по умолчанию |
|---|---|
| Библиотека, язык и настройки | `~/.local/share/vivid/library.json` |
| Миниатюры | `~/.cache/vivid/thumbnails/` |
| Геометрия окна | `~/.config/Vivid/Player.conf` |
| Снимки кадров | `~/Pictures/Vivid/` |
| Резервные копии ассоциаций | `~/.local/share/vivid/association-backups/` |
| Скачанное приложение | `~/.local/share/vivid/app/` |

Учитываются `XDG_DATA_HOME`, `XDG_CONFIG_HOME` и `XDG_CACHE_HOME`. Путь скачивания можно задать через `VIVID_INSTALL_DIR`. Если библиотеки Vivid ещё нет, данные Luma копируются при первом запуске. Удаление записи из библиотеки сохраняет исходный видеофайл.

```bash

.venv/bin/python -m pip install -e .
./run.sh
# Альтернатива для NixOS
nix-shell --run 'python3 -m vivid'
```

```bash
python3 -m pip install build
python3 -m build               # Wheel и архив Python-пакета
nix-build                     # Сборка Nix
```
