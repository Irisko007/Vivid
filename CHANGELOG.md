# Changelog

## 1.3.0 — 2026-10-08

- Added 10 interface languages with English as the initial default.
- Added a language selector in settings with immediate preview and persistent Save / Cancel behavior.
- Updated text without restarting video; added Arabic right-to-left layout.
- Kept the settings dialog open if writing settings fails.
- Added release download, SHA-256 verification, dependency installation and default-player options.
- Added English and Russian documentation, contribution guides and release packaging.

## 1.2.0 — 2026-10-08

- Renamed Luma to Vivid; retained migration of existing library data.
- Added a windowed viewer for files opened externally.
- Added subtle button transitions and animated player controls.
- Registered Vivid as a user-level default video player.

## 1.1.0 — 2026-10-08

- Added IBM Plex Sans, structured navigation and centered playback controls.
- Added six themes with preview and explicit saving.
- Added speed selection, fit / fill / stretch and idle controls.
- Updated file and folder dialogs.

## 1.0.0 — 2026-10-08

- Initial native Qt and mpv player, library, queue, favorites and generated icon.
