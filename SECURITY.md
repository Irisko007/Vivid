# Security

Vivid opens local files through the system mpv and FFmpeg. Keep those packages and Qt up to date using your distribution's package manager.

Report a security issue privately through [GitHub vulnerability reporting](https://github.com/Irisko007/Vivid/security/advisories/new). Include the Vivid version, distribution, affected component, reproduction steps and impact. Do not attach credentials or private media.

Release archives include SHA-256 checksums. The download installer checks the archive before installation. A checksum detects a mismatched download; it is not a cryptographic signature.
